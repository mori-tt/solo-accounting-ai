# REQUIREMENTS.md

## 概要

個人事業主・小規模事業者向けの経理・決算準備・確定申告準備アプリ。
経費・売上・証憑・請求を一元管理し、月次・期次の締め処理と
確定申告に必要な集計を支援する。

## 対象ユーザー

- 個人事業主(フリーランス・請負・小売など)
- 小規模事業者(数人規模の法人・任意団体)

## 用語

- Business: 1つの事業体。データ分離の単位
- Member: Businessに所属するユーザー(ロールを持つ)
- Transaction: 取引(入出金・仕訳の元データ)
- Expense: 経費
- Receipt: 証憑(領収書・請求書などのファイル)
- Fiscal Period: 会計期間(締めの単位)

## 機能要件

### F1: 事業体・メンバー管理

- ユーザーのFirebase Authenticationによるログイン
- Businessの作成・切替
- Memberの招待・ロール管理(owner / editor / viewer)

### F2: 取引・経費管理

- Transactionの登録・編集・削除
- 金額は円単位の整数で保持する
- Receiptファイルのアップロードと紐付け
- 取引への勘定科目の付与

### F3: 売上・請求管理

- Customer・Projectの管理
- Invoiceの作成・発行
- Paymentの記録・Invoiceとの消込
- 未入金Invoiceの検出

### F4: 締め処理

- 月次サマリの集計
- 締めチェックリスト(証憑未添付・未払経費・未入金売上)
- 会計期間の締め・締め済み期間データの変更禁止
- 監査ログ(誰が・いつ・何を変更したか)

### F5: AI支援

- 証憑からの金額・日付・取引先の抽出提案
- 勘定科目の提案
- 重複取引の検出提案
- 月次サマリの自然言語説明
- AI提案はあくまで提案であり、確定はユーザーの承認を必須とする

## 非機能要件

- businessIdをまたいだデータアクセスを禁止する
- 個人情報・証憑内容をログに出力しない
- Security RulesはEmulatorテストで検証する
- 金額は円単位の整数(integer yen)で保存する

## スコープ外(初期版)

- 銀行・クレジットカード連携(API連携)
- 確定申告書の直接作成・e-Tax連携
- 給与計算・社会保険関連
- 複数通貨対応
